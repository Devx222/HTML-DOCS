Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard language used to create web pages. HTML provides the structure for web content, while CSS and JavaScript enhance the styling and functionality.

History of HTML

HTML was created by Tim Berners-Lee in 1991, as part of the World Wide Web project. The goal was to standardize a system for linking documents and allowing them to be easily displayed across different browsers and devices. The first version, HTML 1.0, was released in 1991. Since then, HTML has gone through various versions, with HTML5 being the latest.

Key Milestones in HTML History:

  • 1991: HTML 1.0 - The first version of HTML.
  • 1995: HTML 2.0 - The first official version.
  • 1999: HTML 4.01 - Added support for multimedia elements.
  • 2014: HTML5 - Introduced features like video/audio support and improved semantics.

Important HTML Tags

  • <html> - Defines the document as HTML.
  • <head> - Contains metadata, title, and links to external files.
  • <body> - Contains the visible content of the webpage.
  • <h1> to <h6> - Defines headers, with <h1> being the highest level.
  • <p> - Defines a paragraph of text.
  • <img> - Embeds an image in the page.
  • <a> - Defines a hyperlink.
  • <div> - A container used to group elements.
  • <ul> and <ol> - Define unordered and ordered lists, respectively.

HTML Attributes

Attributes provide additional information about an element. They are added to HTML tags and usually come in name-value pairs.

  • href - Specifies the URL for a hyperlink (<a> tag).
  • src - Specifies the source for an image (<img> tag).
  • alt - Provides alternative text for an image, used for accessibility.
  • class - Specifies one or more class names for an element (used for CSS styling).
  • id - Specifies a unique identifier for an element, useful for styling and JavaScript manipulation.
  • style - Specifies inline CSS styles for an element.
  • target - Defines where to open the linked document (e.g., _blank opens in a new tab).
